SAKURA店舗伝票 v14 - Googleクラウド対応

【1】Googleスプレッドシートを1つ作成
【2】拡張機能 → Apps Script
【3】GoogleAppsScript.gs の内容を貼り付け
【4】CONFIG.API_KEY を長いランダム文字列へ変更
【5】setup() を1回実行して権限を承認
【6】デプロイ → 新しいデプロイ → ウェブアプリ
    実行するユーザー: 自分
    アクセスできるユーザー: 全員
【7】発行された /exec URLをアプリの「☁️ Google保存設定」に入力
【8】同じ店舗キーを入力して「接続設定を保存」
【9】「🔎 接続テスト」または「☁️ 今すぐ同期」

Google側には次の3シートが自動作成・更新されます。
・売上データ
・日別集計
・月別集計

精算、売上削除、バックアップ復元後に、端末内の売上データ全件をGoogleへ同期します。
これにより編集・削除もGoogle側へ反映できます。

注意:
・Apps Script WebアプリのURLと店舗キーは第三者に公開しないでください。
・この方式はGoogleスプレッドシートを売上データのクラウド保管先として使用します。
・ネットワーク障害時は端末側へ保存され、Google同期は次回「今すぐ同期」などで再送できます。
