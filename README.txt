SAKURA店舗伝票 完成版PWA

【公開】
このフォルダ一式をHTTPSで公開してください。
GitHub Pages等の静的HTTPSホスティングで利用できます。

【Android】
1. 公開URLをChromeで開く
2. Chromeメニューから「インストール」または「ホーム画面に追加」
3. 「SAKURA店舗伝票」を追加
4. ホーム画面のアイコンから起動

【重要】
売上データ・品目設定は端末ブラウザのlocalStorageに保存されます。
端末変更やブラウザデータ削除に備えて定期的にバックアップしてください。
PWAのService WorkerはHTTPS配信で利用してください。
